# Ovie in Southern Kaduna

A comprehensive guide to the Ovie programming language — from first principles to production systems.

Written from the perspective of developers in Southern Kaduna, Nigeria, this book shows how a language built with accessibility and low-level power in mind can serve real communities building real software.

## How to Use This Book

Each chapter builds on the previous. If you're new to Ovie, start at Chapter 1.
If you're migrating from another language, Chapter 3 gives you the essentials fast.

All code examples in this book are runnable. Validate them with:

```bash
ovie book test
```

Serve the book locally:

```bash
ovie book serve
```
